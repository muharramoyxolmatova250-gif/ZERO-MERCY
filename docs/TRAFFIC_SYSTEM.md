# ZERO MERCY — Cyberpunk road traffic foundation

## Implemented in the repository
- Added a reusable two-phase intersection signal controller at `scripts/world/cyberpunk_traffic_signal.gd`.
- Procedural districts now place signal objects at selected road-grid intersections.
- Ambient electric cars query nearby signals, brake toward a stop, and accelerate when their travel axis receives a green phase.
- Signal cycle offsets vary by intersection to avoid every junction changing at the exact same moment.

## Current limitations
- The current city traffic actor is a lightweight visual prototype, not a full vehicle physics simulation.
- Its route is a local closed loop generated by the district; it does not yet consume OSM road graphs or navigate between streamed Earth regions.
- The signal controller uses two broad movement axes and does not yet model turn arrows, pedestrian phases, emergency priority, lane queues, collision avoidance, or traffic laws.
- No Godot runtime or visual playtest has been run in this environment. Verify in Godot 4.3+ before treating the system as accepted.

## Next integration targets
1. Convert imported OSM road geometry into a directed lane graph.
2. Route cars through graph nodes and intersections, including turns and roundabouts.
3. Add lane following, safe gaps, collision avoidance, parking, and traffic density controls.
4. Connect airport/rail/metro hubs to the global geographic coordinate and region-streaming systems.
5. Add player-owned vehicle entry/exit, driving camera, damage and save state.
